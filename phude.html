🎧 Phụ đề → Âm thanh

Import SRT/VTT → sửa phụ đề → (tùy chọn) dịch → tải phụ đề mới → xuất file âm thanh khớp mốc thời gian. Xử lý ngay trên trình duyệt.

1Import file phụ đề

Thả file .SRT / .VTT vào đây
hoặc
Chưa có file nào.

2Sửa phụ đề 0 câu

Sửa trực tiếp chữ và mốc giờ (định dạng 00:00:00,000). Ô viền đỏ là mốc không hợp lệ. Nút 🔊 nghe thử một câu theo đúng khoảng thời gian của nó.
Chưa có dữ liệu phụ đề.

3Dịch sang ngôn ngữ khác (tùy chọn)

Bản dịch sẽ thay vào khung “lời hiện tại” ở bước 2; lời gốc vẫn được giữ bên dưới để đối chiếu. Mốc thời gian không đổi.

4Xuất file âm thanh

Đọc từng câu bằng giọng Piper chạy trong trình duyệt, đặt đúng mốc bắt đầu, tăng tốc (giữ nguyên cao độ) khi câu dài hơn khoảng thời gian cho phép, rồi trộn thành một file.
Import phụ đề rồi bấm “Xuất file âm thanh”.
Cần Chrome/Edge và có mạng để tải Piper cùng mô hình giọng lần đầu (sau đó trình duyệt lưu lại). Câu quá dài sẽ được đánh dấu ngay trong bảng ở bước 2 để bạn rút gọn hoặc kéo dài mốc.
