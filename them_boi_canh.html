🗂️ Thư viện tài nguyên

Quản lý ảnh/video bối cảnh, nhạc nền và hiệu ứng âm thanh. Tất cả được lưu trực tiếp vào GitHub để Gemini Studio và phòng dựng video dùng chung.

1 · Thêm tài nguyên

Bạn có thể đổi tên từng file trước khi tải lên. Mỗi file tối đa 45 MB. File trùng tên sẽ bị chặn, không tự ghi đè.
Đang chờ chọn file.

2 · Quản lý thư viện GitHub

Mỗi tài nguyên có thể đổi tên, thay file bằng phiên bản mới hoặc xóa khỏi GitHub. Thao tác sẽ tạo commit trên nhánh main.

Đang tải thư viện...
Lưu ý: GitHub không phải kho lưu trữ video/audio chuyên dụng. Giới hạn trang là 45 MB mỗi file để giảm nguy cơ treo trình duyệt trên điện thoại. Khi thay file, hãy giữ đúng định dạng được hỗ trợ.
