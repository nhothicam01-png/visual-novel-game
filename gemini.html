✨ Gemini Đi

Khu vực thử nhanh Gemini API: kiểm tra kết nối, dịch văn bản, hỏi đáp nhiều lượt và tạo ảnh. API key được lưu riêng trong trình duyệt, không ghi vào GitHub.

🔑 Cấu hình Gemini API

Chưa kiểm tra kết nối.
Lưu ý bảo mật: key được lưu trong localStorage của trình duyệt trên cùng tên miền GitHub Pages để tiện dùng lại. JavaScript trên website này có thể đọc key. Chỉ dùng key cá nhân, không dùng trên thiết bị công cộng; có thể xóa key bất cứ lúc nào. Không gửi key vào GitHub hoặc cho người khác.

💬 Hỏi đáp với Gemini

Bắt đầu cuộc trò chuyện bằng cách nhập câu hỏi bên dưới.

🎨 Tạo ảnh bằng Gemini

Dùng mô hình Gemini Image (Nano Banana). Có thể chọn tỉ lệ và độ phân giải trước khi tạo ảnh.

Các yêu cầu được gửi trực tiếp từ trình duyệt tới Google Gemini API. Tính khả dụng, giới hạn và chi phí phụ thuộc model, khu vực và gói API của Google.
