🔌 Gemini API – Kiểm tra kết nối

Trang kiểm tra độc lập, không cần cài đặt. Gửi một yêu cầu ngắn đến Gemini và hiển thị kết quả hoặc lỗi trả về.

Bảo mật: API key bạn đã dán trong cuộc trò chuyện nên được xem là đã lộ. Hãy thu hồi key đó trong Google AI Studio và tạo key mới. Không dán key cũ vào đây. Trang này không lưu key, nhưng key vẫn được gửi từ trình duyệt tới Google.
Chưa kiểm tra.

Ghi chú: Nếu báo lỗi Failed to fetch hoặc CORS, hãy thử mở file bằng Chrome/Edge và kiểm tra mạng. Nếu báo 400/403/404/429, phần chi tiết bên dưới sẽ giúp xác định nguyên nhân.
