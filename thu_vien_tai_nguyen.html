🗂️ Quản lý thư viện tài nguyên

Quản lý tập trung ảnh, video/WebM, nhạc nền, hiệu ứng âm thanh và hiệu ứng đồ họa. Tài nguyên được đọc và lưu trực tiếp trong repository GitHub đang dùng chung với Gemini Studio và Phòng tạo video.

1. Kết nối và chọn loại tài nguyên

Đang kiểm tra token…Mở GitHub Manager để kết nối

2. Tải tài nguyên lên GitHub

Đích lưu: assets/NhanVat/[thư mục nhân vật]/

Thông tin nhân vật / hoạt ảnh

Các lựa chọn này được lưu trong JSON cạnh từng file upload.

Ví dụ hai nhân vật đối diện nhau: nhân vật trái quay sang phải, nhân vật phải quay sang trái. Góc khuôn mặt là góc nhìn thấy khuôn mặt; khung hình là toàn thân / bán thân / cận cảnh.

Thông tin hiệu ứng cảnh

Metadata giúp phân loại hiệu ứng khi dùng trong phòng tạo video. File vẫn được lưu nguyên định dạng PNG / WEBM.

Upload cần GitHub Token có quyền Contents: Read and write. Nên dùng file tối ưu dung lượng; mỗi file tối đa 90 MB. Tên file trùng sẽ cập nhật file cũ.

3. Danh sách tài nguyên

Nhấn “Tải lại thư viện” để đọc tài nguyên.

4. Chỉnh sửa thông tin tài nguyên

Chưa chọn tài nguyên.

Thông tin được lưu thành file JSON cạnh tài nguyên gốc, ví dụ: nhan_vat.webm.json.

Đường dẫn thư viện: assets/NhanVat · assets/Nen · assets/AmThanh/Nen · assets/AmThanh/HieuUng · assets/HieuUng
