# Phương tiện

Lưu ảnh/video phương tiện dùng trong `scene_objects`.

Ví dụ: `xe_cuu_thuong.png`, `xe_may.png`, `o_to.webm`.

Trong JSON, tham chiếu bằng đường dẫn đầy đủ bắt đầu từ `assets/`, ví dụ:

```json
{"id":"ambulance_01","asset":"assets/PhuongTien/xe_cuu_thuong.png"}
```

Ưu tiên PNG nền trong suốt cho vật thể tĩnh; WEBM nền trong suốt cho chuyển động dựng sẵn.
