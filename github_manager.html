🔐 GitHub Manager

Quản lý token một lần, sau đó dùng cùng token trên các trang cùng tên miền GitHub Pages. Có thể đẩy file HTML, JS, CSS, JSON và các tệp khác lên repository.

1. Kết nối GitHub

Chưa kiểm tra kết nối.
Bảo mật: token được lưu trong localStorage của trình duyệt để các trang cùng origin dùng chung. Mọi JavaScript chạy trên website này đều có thể đọc token. Chỉ dùng token Fine-grained giới hạn đúng repository, chỉ cấp Contents: Read and write; không cấp quyền quản trị. Không dùng trên máy công cộng. Khi nghi ngờ lộ token, hãy thu hồi token tại GitHub.

2. Repository đích

Nếu đường dẫn đã tồn tại, hệ thống sẽ cập nhật file. Nếu chưa tồn tại, hệ thống sẽ tạo file mới.
